# Gateway Phase 2 (Hybrid Routing + `sous claude` Launcher) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the gateway a hybrid: requests for `[gateway].local_models` keep being served by the local model, every other request Claude Code sends to its `ANTHROPIC_BASE_URL` is forwarded to `api.anthropic.com` byte-for-byte with the user's own credentials, and a `sous claude` verb launches Claude Code so its Task-tool subagents run locally while the main loop stays on the subscription — the spec's Phase 2 exit: one session, frontier main loop on verified subscription billing, subagents local, task completed.

**Architecture:** One new module, `src/sous/gateway/upstream.py`, owns forwarding: an `httpx.AsyncClient` to one fixed origin, RFC 9110 hop-by-hop header handling, raw-byte relay of the upstream response as a Starlette `StreamingResponse`, and Anthropic-shaped `502`/`504` errors for failures of the forwarding itself. `routes.py` gains the routing predicate (`model` in the decoded body, after stripping Claude Code's bracketed beta suffix) on the two Messages routes, plus a catch-all `/{path:path}` route that streams everything else through — Claude Code 2.1.247 also calls `/api/hello`, `/api/oauth/usage`, `/api/oauth/account/settings`, `/api/event_logging/v2/batch` and more on the base URL. `cli.py` gains `sous claude`, which probes the daemon, sets the oMLX-derived environment **minus every credential and tier variable**, and `exec`s `claude`. Docs (README, SECURITY.md, CONTRIBUTING.md, CLAUDE.md) gain the gateway boundary. The local-serving path (`convert.py`, `response.py`, `turn.py`, the engine stack) is untouched.

**Tech Stack:** Python 3.14, uv, mcp 2.x (`MCPServer.custom_route` — custom routes are mounted *after* the `/mcp` mount, so a catch-all cannot shadow it), starlette 1.6 (`StreamingResponse`, `Request.stream()`), httpx 0.28 (promoted from dev-only to a runtime dependency; `AsyncClient.send(stream=True)`, `Response.aiter_raw()`, `ASGITransport`/`MockTransport` in tests), anyio (shielded close), pytest (in-process ASGI tests; `slow` real-socket tests with two in-process uvicorn servers).

**Spec:** `docs/superpowers/specs/2026-08-26-hybrid-gateway-design.md` — Phase 2 section, the core-decisions table rows "Routing predicate", "Client configuration", "Upstream auth", and "Security posture"; checklist item 9 (launcher side). Phase 0 wire facts are on issue #41 (comments 5440572099 and 5440844229); the Phase 1 exit report (comment 5519883107) recorded the `sous-local[1m]` suffix this plan handles. Phase 1's plan (`docs/superpowers/plans/2026-09-02-gateway-phase1-endpoint.md`) is the record of what the endpoint already does; its decision 16 ("Phase 2 forwards `/api/hello` upstream like any non-local request") is honoured here.

## Global Constraints

- Python >= 3.14; everything runs via `uv run`. Never pip. `except A, B:` without parentheses is valid 3.14 syntax (PEP 758) — don't "fix" it.
- Type-suppression pragmas are `# ty: ignore[rule]`, never `# type: ignore`. `uv run ty check` covers tests too.
- mlx / mlx_lm / mlx_vlm imports stay function-local. Nothing in this plan touches an mlx-calling thread; if a task somehow does, the thread calls `sous.engine.base.release_mlx_thread_state()` before it exits (ml-explore/mlx#4327).
- **The gateway never executes a tool** (spec core decision "Tool execution: Never"). Forwarding changes nothing here: `toolexec.py` is not imported by anything under `src/sous/gateway/`.
- **Request bodies, header values and query strings are never logged, at any level.** A forwarded request contributes exactly: the word `upstream`, the method, a bounded printable path, a bounded printable model id when the body named one (else `-`), the upstream's status, and seconds. The upstream's response is never logged either.
- **Forwarded requests are byte-exact and header-faithful** (spec "Upstream auth"): the body sent upstream is the bytes received, never re-serialized; end-to-end headers travel in their original order with duplicates intact; only `Host` (regenerated by httpx for the upstream origin), the hop-by-hop headers of RFC 9110 §7.6.1 plus those named in `Connection`, and — on the buffered routes only — `Content-Length` (recomputed from the exact bytes) are removed. Nothing is added to a forwarded request beyond httpx's defaults for headers the client omitted (`accept`, `user-agent`, `connection`, and `accept-encoding: identity`). Responses gain exactly one header: `Via: 1.1 sous`.
- **sous stores no credential and adds none**: `httpx.AsyncClient(trust_env=False)` — no `~/.netrc`, no `HTTPS_PROXY`; `follow_redirects=False`; no retries (Claude Code retries). A plaintext (`http://`) upstream is accepted only for a loopback host (`127.0.0.1`, `localhost`, `::1`).
- **The launcher sets no credential and no tier variable**: never `ANTHROPIC_AUTH_TOKEN`, never `ANTHROPIC_API_KEY`, never `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL` (spec "Client configuration"). It warns when the inherited environment already carries a credential variable, and launches anyway.
- **Honest model id**: unchanged from Phase 1 (`[gateway].local_models` rejects anything containing `claude`). Routing matches the id after stripping one trailing `[…]` suffix; the response echoes the id exactly as sent.
- **Loopback only**: the existing `Host`/`Origin` checks (`_check_loopback`) run on every route, forwarded ones included — the gateway is a loopback-only proxy to one configured origin.
- **Client disconnect never wedges anything**: on a forwarded stream, a client hang-up closes the upstream connection (shielded `aclose()`); local turns keep Phase 1's drain-to-completion.
- Tests never touch the real `~/.sous`: every `SousConfig` in tests is built with tmp_path-based `data_dir`/`config_path`. **Tests never touch the network**: every test `Gateway` is built with a fake `Upstream` (in-process ASGI transport) or a loopback `upstream_url`; the default `https://api.anthropic.com` client is constructed but never connected in tests. `slow`-marked tests run for real, never mocked.
- `docs/superpowers/**` are point-in-time records: never edit existing spec/plan files (this plan is a new file).
- Conventional Commits, imperative lowercase subject, *why* in the body. Commit trailer: `Co-Authored-By: Claude <noreply@anthropic.com>` (model-less, per the user's global CLAUDE.md). Work on a branch (`feat/gateway-phase2`); `main` is protected. CI is exactly: `uv run pytest -m "not model"`, `uv run ty check`, `uv run ruff check . && uv run ruff format --check .`, `uv lock --check`. The code blocks in this plan are written for readability, not pre-wrapped: every commit step runs `uv run ruff format .` *before* `uv run ruff check .`.

## Decisions this plan locks (beyond the spec)

Settled by probing the installed libraries (mcp, httpx 0.28.1, starlette 1.6.0, uvicorn 0.52.3) and the Claude Code 2.1.247 binary; implementers should not reopen them.

1. **A catch-all route forwards everything the gateway does not serve.** Gate 1 (headless `claude -p`) saw only `POST /v1/messages` and `HEAD /api/hello`, but the 2.1.247 binary references `/api/oauth/usage`, `/api/oauth/account/settings`, `/api/event_logging/v2/batch`, `/api/organization/claude_code_first_token_date`, `/api/claude_code_grove` and others on the same base URL — an interactive session that cannot reach them degrades in ways a gateway user would blame on sous. `custom_route("/{path:path}", methods=[GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS])` streams them through (body streamed, not buffered). The SDK appends custom routes after its `/mcp` mount ("mount these routes last, so they have the lowest route matching precedence"), so `/mcp` is never shadowed; a method the two Messages routes do not take (`GET /v1/messages`) falls through to the catch-all and gets the upstream's own answer. `/api/hello` is no longer answered locally — it is forwarded like everything else (Phase 1 decision 16).
2. **The claim predicate is "the body decodes and names a local model"; everything else is the upstream's to judge.** `POST /v1/messages` and `/v1/messages/count_tokens` read the body (32 MiB cap, as today), decode it with the strict decoder, and serve it locally only when `body["model"]` is a string whose id — after stripping one trailing bracketed suffix (`sous-local[1m]` → `sous-local`; regex `\[[^\[\]]*\]$`) — is in `[gateway].local_models`. A body that does not decode, is not an object, has no string `model`, or names any other id is forwarded verbatim; the upstream's 400/404 comes back in its own words. Consequence stated: sous's `400 request body is not valid JSON` now applies only to bodies that decode and name a local model — a body that fails to decode cannot name one. `MAX_BODY_DEPTH` is checked only on claimed bodies (a forwarded body is never re-serialized, which is what the depth cap guards).
3. **The forwarded body is the raw bytes already read.** Both Messages routes had to read the body to look at `model`; they hand those same bytes to the forwarder, which drops the client's `Content-Length` (httpx recomputes it from the exact bytes, so a client that lied cannot desync the upstream connection). The catch-all passes `request.stream()` through with the client's `Content-Length` kept (verified: httpx honours a supplied `Content-Length` and adds no `Transfer-Encoding` beside it). A GET/HEAD with no body sends no body framing at all (`_has_body` — httpx would otherwise frame an empty iterator as chunked).
4. **Response fidelity: raw bytes, raw header pairs.** The upstream's status is relayed as-is; its body via `aiter_raw()` (still compressed if it was compressed, so `Content-Encoding` and `Content-Length` stay truthful); its headers as raw `(bytes, bytes)` pairs assigned to `StreamingResponse.raw_headers` (a Mapping would collapse repeated headers), minus hop-by-hop, minus `Date` and `Server` (uvicorn prepends its own; forwarding the upstream's would send both), plus `Via: 1.1 sous`. Trailers are not forwarded (httpx does not surface them). Requests carry no `Via`: nothing that could make the upstream treat a proxied request differently is added.
5. **Forwarding failures are Anthropic-shaped and carry `Via`.** Before any byte of the upstream response is relayed: `httpx.TimeoutException` → `504 api_error "upstream <host> timed out"`; any other `httpx.HTTPError` (connect refused, DNS, protocol error) → `502 api_error "could not reach upstream <host>: <ExceptionClassName>"` — the class name, never the exception text (it can quote the wire); `starlette.requests.ClientDisconnect` while streaming the request body up → `400` (nobody reads it; it keeps the disconnect from being a traceback). After the upstream's headers are on the wire, a mid-body `httpx.HTTPError` ends the body early — uvicorn closes short of the declared length and the client sees a truncated response, which is the truth.
6. **Timeouts and limits**: `httpx.Timeout(connect=10.0, read=600.0, write=60.0, pool=None)` (read is the gap between bytes — Anthropic streams pings while it thinks, and its own SDK defaults to 600 s); `httpx.Limits(max_connections=None, max_keepalive_connections=20)` — one Claude Code session opens a handful of connections, and a cap would only ever turn a burst into an untimed pool wait; HTTP/1.1 only (no `h2` dependency); `headers={"accept-encoding": "identity"}` at the client level so a client that sent no `Accept-Encoding` does not get httpx's `gzip, deflate` asked for on its behalf and then receive compressed raw bytes it never said it could decode (a client's own header overrides this per request). Forwarded requests are **not** counted against `MAX_PENDING_TURNS`/`MAX_PENDING_COUNTS`: those bound local generation.
7. **`[gateway].upstream_url`** (default `https://api.anthropic.com`) is an *origin* — scheme + host[:port], no path, query, fragment or userinfo; `https://` anywhere, `http://` only for a loopback host (the forwarded requests carry the OAuth token; plaintext to anywhere else would put it on the wire in the clear). Anything else warns and falls back to the default. A trailing `/` is tolerated and dropped. The knob exists for the real-socket tests and for anyone fronting Anthropic with their own gateway; it is not a way to point Claude Code at a different vendor.
8. **`sous claude` is `exec`, not a subprocess**: `os.execve(claude, [claude, *args], env)` replaces the process, so the TTY, signals and exit code are Claude Code's own. Every argument after `claude` passes through untouched — dispatch happens *before* argparse (`argparse.REMAINDER` cannot pass through a leading `-p`), so `sous claude --help` shows Claude Code's help, not sous's.
9. **`--disallowedTools LSP` is appended, not prepended, and goes before a `--` if the user passed one.** Claude Code's option is variadic (`--disallowedTools, --disallowed-tools <tools...>`): prepending it would swallow a positional prompt (`claude --disallowedTools LSP "fix the bug"` reads the prompt as a tool name). It is omitted when the user's arguments already contain `--disallowedTools`, `--disallowed-tools`, or either with `=` (spec checklist item 9).
10. **The launcher sets `CLAUDE_CODE_MAX_CONTEXT_TOKENS` but NOT `CLAUDE_CODE_AUTO_COMPACT_WINDOW` — amending spec checklist item 9 for hybrid mode.** Claude Code honours `CLAUDE_CODE_MAX_CONTEXT_TOKENS` only for non-`claude-*` ids (Phase 0/1 fact), so it bounds the local subagent's window and leaves the frontier main loop alone. `CLAUDE_CODE_AUTO_COMPACT_WINDOW` is *global*: the 2.1.247 binary's own `/config` copy reads "The actual threshold is the minimum of this setting and your model's maximum context window", with per-source labels "(from CLAUDE_CODE_AUTO_COMPACT_WINDOW) / (default for this model) / (default for an unrecognized model)". Pinning it to 65536 would make the frontier main loop auto-compact at 65K — the opposite of the product's goal — while the subagent's threshold is already bounded by its (max-context-tokens) window. The whole-session-local recipe in CONTRIBUTING.md keeps setting both, because there every model *is* local. Task 7 verifies the main loop's window in the live session.
11. **`API_TIMEOUT_MS=3000000` is set unconditionally** (oMLX's contract, spec item 9): it governs the main loop too, and a cold model load plus a long prefill is the only reason it exists. `ANTHROPIC_BASE_URL`, `CLAUDE_CODE_SUBAGENT_MODEL` (the first `[gateway].local_models` entry) and `CLAUDE_CODE_MAX_CONTEXT_TOKENS` (`[gateway].max_context_tokens`) are set unconditionally as well — they must be exactly what the daemon serves. The launcher prints the four values it set on stderr before `exec`, so the environment is never a surprise; it prints nothing that could be a secret.
12. **The launcher probes `HEAD /api/hello` and reads `Via`.** Nothing is listening → refuse (`sous serve`); `404` without `Via: 1.1 sous` → the daemon is running without the gateway mounted (config edited, daemon not restarted) → refuse with restart advice; `5xx` with `Via` → the gateway is up but the upstream is not reachable right now → warn and launch anyway (Claude Code's own error is the truth); anything else (including a Phase 1 daemon's local `200` without `Via`) → launch. The probe uses stdlib `http.client`, not httpx — the CLI must not pay an async client's import cost for `sous status`.
13. **Gateway shutdown closes the upstream client.** `Gateway.aclose()` = `close()` + `await upstream.aclose()`, awaited from `create_server`'s lifespan hook (already async). `Gateway.close()` stays sync for existing callers.
14. **Test plumbing is dependency injection, not monkeypatching**: `Upstream(base_url, *, transport=None)` accepts an `httpx.AsyncBaseTransport`; `Gateway(engines, config, upstream=None)`, `mount_gateway(mcp, engines, config, *, upstream=None)` and `create_server(store, engines, config, *, upstream=None)` thread it through. Unit tests use `tests/fake_upstream.py::FakeUpstream` (a recording Starlette app behind `httpx.ASGITransport`); real-socket tests serve a Starlette app under uvicorn on a second loopback port and point `[gateway].upstream_url` at it.
15. **WebSocket upgrades are not forwarded** (`/api/ws/speech_to_text/voice_stream`): an ASGI `websocket` scope matches no route and Starlette closes it; an HTTP request carrying `Upgrade` loses that hop-by-hop header and gets the upstream's plain answer. Documented as a limitation, no code.

```python
def _upstream_url(gateway: dict) -> str:
    """The forwarding target as an origin — scheme + host[:port] and nothing
    else. A path or query would silently change what is forwarded; userinfo
    would be a credential sous stored; http is allowed only to loopback."""
    value = gateway.get("upstream_url", GATEWAY_DEFAULT_UPSTREAM)
    if isinstance(value, str):
        try:
            parts = urlsplit(value)
        except ValueError:
            # An unbalanced IPv6 bracket makes urlsplit raise rather than return.
            parts = None
        if (
            parts is not None
            and parts.hostname
            and parts.username is None
            and parts.password is None
            and parts.path in ("", "/")
            and not parts.query
            and not parts.fragment
            and (
                parts.scheme == "https"
                or (parts.scheme == "http" and parts.hostname in _LOOPBACK_HOSTS)
            )
        ):
            return f"{parts.scheme}://{parts.netloc}"
    warnings.warn(
        f"sous config: [gateway].upstream_url {value!r} must be an https origin with no "
        f"path (plain http only for a loopback host); using {GATEWAY_DEFAULT_UPSTREAM}",
        stacklevel=3,
    )
    return GATEWAY_DEFAULT_UPSTREAM
```

Create `src/sous/gateway/upstream.py`:

```python
"""Forwarding of everything the gateway does not serve itself.

A transparent HTTP/1.1 proxy to one fixed origin: the bytes the client sent
are the bytes the upstream gets, end-to-end headers travel unmodified (in
their original order, duplicates included), and the upstream's status,
headers and body come back untouched. Only what a proxy must change changes:
`Host`, the hop-by-hop headers of RFC 9110 §7.6.1, and a `Via` on the way
back. Never logs anything; never adds a credential (no netrc, no proxy
environment — trust_env is off).
"""

from __future__ import annotations

from collections.abc import AsyncIterator
from urllib.parse import quote

import anyio
import httpx
from starlette.requests import ClientDisconnect, Request
from starlette.responses import JSONResponse, Response, StreamingResponse

# RFC 9110 §7.6.1: hop-by-hop headers describe one connection, not the
# message, and must not be forwarded — plus whatever `Connection` itself
# names. proxy-connection is the pre-standard spelling some clients still send.
_HOP_BY_HOP = frozenset(
    {
        b"connection",
        b"keep-alive",
        b"proxy-authenticate",
        b"proxy-authorization",
        b"proxy-connection",
        b"te",
        b"trailer",
        b"transfer-encoding",
        b"upgrade",
    }
)
# uvicorn prepends its own Date and Server to every response; forwarding the
# upstream's copies would send both.
_SERVER_OWNED = frozenset({b"date", b"server"})
# RFC 9110 §7.6.3. On every response this module produces — relayed or its
# own error — so a client (the `sous claude` launcher) can tell "the gateway
# forwarded this" from "the daemon has no such route". Never added to a
# request: nothing that could make the upstream treat a proxied request
# differently goes up.
VIA = "1.1 sous"
# connect: a dead network fails fast. read: the gap between bytes, not the
# whole response — Anthropic streams pings while it thinks, and its own SDK
# defaults to 600s. write: per chunk of a body up to 32 MiB. pool: connections
# are unlimited below, so nothing ever waits for one.
TIMEOUT = httpx.Timeout(connect=10.0, read=600.0, write=60.0, pool=None)


def _connection_named(raw: list[tuple[bytes, bytes]]) -> frozenset[bytes]:
    names: set[bytes] = set()
    for name, value in raw:
        if name.lower() == b"connection":
            names.update(t.strip().lower() for t in value.split(b",") if t.strip())
    return frozenset(names)


def request_headers(
    raw: list[tuple[bytes, bytes]], *, drop_content_length: bool
) -> list[tuple[bytes, bytes]]:
    """The client's headers as the upstream should see them: same order, same
    duplicates, minus Host (httpx derives it from the upstream URL) and the
    hop-by-hop set. Content-Length goes too when the body was buffered — httpx
    recomputes it from the exact bytes, so a client that lied cannot desync
    the upstream connection."""
    drop = _HOP_BY_HOP | _connection_named(raw) | {b"host"}
    if drop_content_length:
        drop = drop | {b"content-length"}
    return [(name, value) for name, value in raw if name.lower() not in drop]


def response_headers(raw: list[tuple[bytes, bytes]]) -> list[tuple[bytes, bytes]]:
    """The upstream's headers as the client should see them, plus Via.
    Content-Length and Content-Encoding stay: the body is relayed as the raw
    bytes they describe."""
    drop = _HOP_BY_HOP | _connection_named(raw) | _SERVER_OWNED
    kept = [(name, value) for name, value in raw if name.lower() not in drop]
    kept.append((b"via", VIA.encode("ascii")))
    return kept


def _has_body(request: Request) -> bool:
    # httpx frames any iterable content as chunked when no length is declared;
    # a GET or HEAD must go out with no body at all, not an empty chunked one.
    length = request.headers.get("content-length")
    if length is not None:
        return length != "0"
    return "transfer-encoding" in request.headers


def _target_path(request: Request) -> bytes:
    # raw_path is the percent-encoded path exactly as received (ASGI leaves
    # it optional, so fall back to re-encoding the decoded one); the query
    # string is always raw bytes.
    path = request.scope.get("raw_path") or quote(request.url.path).encode("ascii")
    query = request.scope.get("query_string", b"")
    return path + b"?" + query if query else path


def _error(status: int, message: str) -> JSONResponse:
    return JSONResponse(
        {"type": "error", "error": {"type": "api_error", "message": message}},
        status_code=status,
        headers={"via": VIA},
    )


async def _relay(response: httpx.Response) -> AsyncIterator[bytes]:
    try:
        async for chunk in response.aiter_raw():
            yield chunk
    except httpx.HTTPError:
        # Headers are already on the wire, so this can only end the body
        # early; uvicorn closes the connection short of the declared length
        # and the client sees a truncated response, which is the truth.
        return
    finally:
        # Also reached when the client hangs up: Starlette cancels the
        # streaming task, and inside a cancelled scope an await is skipped
        # unless shielded — the upstream connection would otherwise stay open
        # (and the upstream generating) until its read timeout.
        with anyio.CancelScope(shield=True):
            await response.aclose()


class Upstream:
    def __init__(self, base_url: str, *, transport: httpx.AsyncBaseTransport | None = None):
        self._base = httpx.URL(base_url)
        self._client = httpx.AsyncClient(
            transport=transport,
            timeout=TIMEOUT,
            # One Claude Code session opens a handful of connections; a cap
            # would only ever turn a burst into an untimed pool wait.
            limits=httpx.Limits(max_connections=None, max_keepalive_connections=20),
            # A 3xx is the upstream's answer; the client follows it, not sous.
            follow_redirects=False,
            # No ~/.netrc, no HTTPS_PROXY: sous must never add a credential
            # the client did not send, and must never route the ones it did
            # send anywhere but the configured origin.
            trust_env=False,
            # httpx would otherwise ask for gzip on the client's behalf, and
            # the raw bytes relayed back would be compressed for a client that
            # never said it could decompress them. A client that does say so
            # overrides this per request.
            headers={"accept-encoding": "identity"},
        )

    @property
    def host(self) -> str:
        return self._base.host

    async def forward(self, request: Request, body: bytes | None) -> Response:
        """Relay `request` to the upstream. `body` is the already-read body
        (the routes that had to look inside it) or None to stream the client's
        body through untouched. Never raises: every failure of the forwarding
        itself is an Anthropic-shaped error carrying Via."""
        content: bytes | AsyncIterator[bytes] | None
        if body is not None:
            content = body
        elif _has_body(request):
            content = request.stream()
        else:
            content = None
        upstream_request = self._client.build_request(
            request.method,
            self._base.copy_with(raw_path=_target_path(request)),
            headers=request_headers(request.headers.raw, drop_content_length=body is not None),
            content=content,
        )
        try:
            response = await self._client.send(upstream_request, stream=True)
        except httpx.TimeoutException:
            return _error(504, f"upstream {self.host} timed out")
        except httpx.HTTPError as e:
            # ConnectError, RemoteProtocolError, ...: the class name says
            # which without quoting anything from the wire.
            return _error(502, f"could not reach upstream {self.host}: {type(e).__name__}")
        except ClientDisconnect:
            # The client left while its body was still streaming up. Nobody
            # reads this; it keeps the disconnect from being a traceback.
            return _error(400, "client disconnected mid-body")
        relayed = StreamingResponse(_relay(response), status_code=response.status_code)
        # Raw pairs, not a mapping: a Mapping would collapse repeated headers.
        relayed.raw_headers = response_headers(response.headers.raw)
        return relayed

    async def aclose(self) -> None:
        await self._client.aclose()
```

async def _read_body(request: Request) -> bytes:
    declared = request.headers.get("content-length", "")
    # isdecimal, not isdigit: "²" is a digit to str but not to int(), and a
    # 5000-digit value trips int()'s digit limit — either would be a bare
    # ValueError here, outside the shaped-error handling. Anything longer
    # than the cap's own digit count is oversized without converting it.
    if declared.isdecimal() and (
        len(declared) > len(str(MAX_REQUEST_BYTES)) or int(declared) > MAX_REQUEST_BYTES
    ):
        raise RequestError(
            413, "request_too_large", f"request body exceeds {MAX_REQUEST_BYTES} bytes"
        )
    chunks: list[bytes] = []
    size = 0
    try:
        async for chunk in request.stream():
            size += len(chunk)
            if size > MAX_REQUEST_BYTES:
                raise RequestError(
                    413, "request_too_large", f"request body exceeds {MAX_REQUEST_BYTES} bytes"
                )
            chunks.append(chunk)
    except ClientDisconnect:
        # Nobody will read this response; it exists so the disconnect is not
        # a 500 with a traceback in the daemon log.
        raise RequestError(400, "invalid_request_error", "client disconnected mid-body") from None
    return b"".join(chunks)

# What `sous claude` sets, and — as important — what it never sets. Either
# credential variable switches Claude Code from the subscription login to
# API-credit billing (the load-bearing #41 fact); the tier variables would pull
# the main loop onto the local model. oMLX's launcher sets all of them because
# it never forwards anything; sous forwards the main loop, so it must not.
_CREDENTIAL_VARS = ("ANTHROPIC_AUTH_TOKEN", "ANTHROPIC_API_KEY")
_DISALLOWED_FLAGS = ("--disallowedTools", "--disallowed-tools")
_LSP_OFF = ["--disallowedTools", "LSP"]
# Model load plus a long prefill: minutes, not the SDK's default.
_API_TIMEOUT_MS = "3000000"
_PROBE_TIMEOUT_SECONDS = 15.0


def claude_argv(user_args: list[str]) -> list[str]:
    """The user's arguments plus `--disallowedTools LSP` (a language server
    connecting mid-session appends its schema to every request and re-prefills
    the conversation) unless they chose their own. Appended, never prepended:
    the option is variadic, so ahead of a positional prompt it would swallow
    the prompt as a tool name. Ahead of a `--`, which ends Claude Code's
    option parsing, if there is one."""
    for arg in user_args:
        if arg in _DISALLOWED_FLAGS or arg.startswith(tuple(f"{f}=" for f in _DISALLOWED_FLAGS)):
            return list(user_args)
    if "--" in user_args:
        end = user_args.index("--")
        return [*user_args[:end], *_LSP_OFF, *user_args[end:]]
    return [*user_args, *_LSP_OFF]


def claude_env(config: SousConfig, base: Mapping[str, str]) -> dict[str, str]:
    """The inherited environment plus the four variables the gateway needs.

    CLAUDE_CODE_MAX_CONTEXT_TOKENS is honoured only for non-claude-* ids, so
    it sizes the local subagent's window and leaves the main loop alone.
    CLAUDE_CODE_AUTO_COMPACT_WINDOW is deliberately NOT set: it is global
    ("the minimum of this setting and your model's maximum context window",
    per Claude Code's own /config copy), so pinning it to the local window
    would make the frontier main loop compact far too early. The subagent's
    threshold is already bounded by its window.
    """
    env = dict(base)
    env["ANTHROPIC_BASE_URL"] = f"http://127.0.0.1:{config.server_port}"
    env["CLAUDE_CODE_SUBAGENT_MODEL"] = config.gateway_local_models[0]
    env["CLAUDE_CODE_MAX_CONTEXT_TOKENS"] = str(config.gateway_max_context_tokens)
    env["API_TIMEOUT_MS"] = _API_TIMEOUT_MS
    return env


def _probe_gateway(port: int) -> tuple[int, bool] | None:
    """(status, did the gateway forward it?) for HEAD /api/hello, or None when
    nothing is listening. A forwarded answer — or the forwarder's own error —
    carries `Via: 1.1 sous`; the daemon's own "no such route" 404 does not.
    stdlib http.client on purpose: the CLI should not pay for an async HTTP
    client to run `sous status`."""
    conn = http.client.HTTPConnection("127.0.0.1", port, timeout=_PROBE_TIMEOUT_SECONDS)
    try:
        conn.request("HEAD", "/api/hello")
        response = conn.getresponse()
        return response.status, "sous" in (response.getheader("via") or "")
    except OSError, http.client.HTTPException:
        return None
    finally:
        conn.close()

    config = load_config()
    if not config.gateway_enabled:
